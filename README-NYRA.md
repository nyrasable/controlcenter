# Nyra Control Center — Vercel V1

Required Vercel env vars:
- TIKTOK_CLIENT_KEY
- TIKTOK_CLIENT_SECRET
- SESSION_SECRET
- APP_URL=https://controlcenter-beige.vercel.app

TikTok redirect URI:
https://controlcenter-beige.vercel.app/api/oauth/callback

Upload these files/folders to the repository root. Keep terms.html and privacy.html. Never put TikTok secrets in GitHub.
